# Contributing

Start by reproducing a labeled case. A useful change should explain what evidence was previously mishandled and show the resulting behavior.

Run `python -m unittest discover -s tests -v` and `python -m pantrytrace evaluate`. Keep fixture mode independent of network access and optional sponsor dependencies. Preserve uncertainty when data conflicts, preserve original evidence IDs, and keep all operational actions as human-approved drafts.

Separate pre-event work from eligible-window implementation. Document new dependencies, source licenses and any changed sponsor contracts. Research suggestions and operator feedback should distinguish observations from hypotheses.
